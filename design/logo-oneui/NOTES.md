# 2160 Player — иконка в стиле One UI

Язык One UI 7–9: сквиркл с большим радиусом, одна крупная простая форма, мягкие многоцветные градиенты,
полупрозрачные «стеклянные» слои с лёгкой глубиной, мягкие тени и световой кант вместо фасок.
Всё нарисовано из собственных контуров, шрифты не используются. Шрифт для «2160 Player» — свой округлый
моноширинный по толщине гротеск, построенный в `oneui.py`. Торговые знаки Samsung не используются;
системные иконки в превью — условные заглушки.

## Концепты
* **A «Слои»** (`concept-A-layers-*`). Три полупрозрачных треугольника Play, наложенных друг на друга
  (как кадры при перемотке), на градиенте амбер → коралл, с тёмно-синим бейджем «2160».
* **B «Монограмма 21/60»** (`concept-B-monogram-*`). Округлые цифры 21/60 на стеклянной карточке поверх
  градиента амбер → оранжевый.
* **C «Экран»** (`concept-C-screen-*`). Стеклянный экран с янтарным Play на глубоком фиолетово-синем фоне.

Для каждого концепта есть: `-icon.svg` (512, сквиркл), `-foreground.svg`, `-background.svg`, `-monochrome.svg`
(адаптивные слои на холсте 108 dp = 512 px, знак внутри безопасного круга 66 dp), `-header-dark.svg` и
`-header-light.svg` (прозрачный фон), `-tv-banner.svg` (320×180).

## Рекомендация
**A «Слои».** Он сразу читается как видеоплеер на 48 px и органичнее всего смотрится рядом с системными иконками
One UI, а бейдж «2160» сохраняет бренд. PNG-набор для Android лежит в `final/`.

## Технически
* В иконках нет фильтров и масок. Мягкие тени сделаны стопкой полупрозрачных смещённых копий, поэтому SVG
  переводятся в VectorDrawable (градиенты через `aapt:attr`, API 24+).
* Монохромный слой — белый силуэт для тематических иконок Android 13+.
* Перегенерировать: `python oneui.py` (SVG + preview.html), `python render.py 3600` (скриншоты),
  `python export_final.py A` (PNG-набор в `final/`).
