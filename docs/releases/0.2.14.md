**Какой APK скачать:** `arm` - подходит любому телефону и ТВ (рекомендуется). `arm64-v8a` / `armeabi-v7a` - поменьше, под одну архитектуру; `universal` - для всего, включая x86.

**Плеер**
- Прошедшее время больше не обрезается, пока длина файла ещё неизвестна (буфер на телефоне в портрете показывал «3:2» вместо «3:29»). Коробка меряется по самой широкой строке текущего формата: `--:--`, `m:ss`, `mm:ss` или `h:mm:ss`. Когда длина известна, резерв снова только под этот формат.
- Ширина по-прежнему считается при смене длительности и масштаба шрифта, не на каждом тике. Цифры табличные, обновление остаётся в слое отрисовки.
- То же для остатка: коробка не уже реальной строки «−остаток / длительность».

Библиотека: `tv.p2160:player-core:0.2.14` (versionCode 26).

**English:** The elapsed readout no longer clips while duration is still unknown (a portrait phone in buffering showed "3:2" instead of "3:29"). The box reserves the widest of `--:--`, `m:ss`, `mm:ss` and `h:mm:ss` for that phase, and only the current duration format once the length is known. Width is measured when the duration or font scale changes, not on each tick. Digits stay tabular and the update stays in the draw phase. The remaining-time box is at least as wide as the drawn string. Library: `tv.p2160:player-core:0.2.14` (versionCode 26).
