**Какой APK скачать:** `arm` - подходит любому телефону и ТВ (рекомендуется). `arm64-v8a` / `armeabi-v7a` - поменьше, под одну архитектуру; `universal` - для всего, включая x86.

**Плеер**
- AVI с MPEG-4 Part 2 (XviD/DivX). На Allwinner H618 первые кадры проходили, затем «Ошибка декодера», и режим FFmpeg не помогал. Две причины. Packed bitstream кладёт B-кадр в тот же буфер, что и опорный: MediaCodec ждёт один кадр и падает. И `getCodecName` в nextlib не знал `video/mp4v-es`, хотя `mpeg4` уже есть в `libavcodec`.
- Packed B-кадры распаковываются до декодера (как `mpeg4_unpack_bframes`). Fourcc `DIV3`/`DIV4` читается как MS-MPEG4 (`video/mp43`).
- В режиме «Авто» ошибка видео посреди потока для этого MIME переключает на программный MediaCodec (`c2.android` / `OMX.google`), затем на FFmpeg. Другие ролики в плейлисте остаются на аппаратном декодере.
- Сообщение об ошибке называет кодек. Если FFmpeg этот кодек не декодирует, так и написано, без совета «просто включите FFmpeg».
- Размер APK не вырос: отдельный декодер не добавлялся, сопоставлены уже вшитые имена. Класс `FfmpegLibrary` собран внутрь `player-core` (и в APK, и в опубликованный AAR). Вторую зависимость `nextlib-media3ext` подключать не нужно: будет две копии класса.

Библиотека: `tv.p2160:player-core:0.2.16` (versionCode 28).

**English:** AVI with MPEG-4 Part 2 (XviD/DivX) showed a few frames on an Allwinner H618 and then a decoder error. FFmpeg mode did not help. Packed B-frames share a buffer with the reference frame, which MediaCodec rejects, and nextlib never mapped `video/mp4v-es` even though `mpeg4` is already in `libavcodec`. Packed frames are unpacked before decode. `DIV3`/`DIV4` is read as MS-MPEG4. In Auto, a mid-stream video decoder error retries the software MediaCodec for that MIME, then FFmpeg. The error names the codec. The APK does not grow. `FfmpegLibrary` is compiled into player-core, so a module dependency and the published AAR both carry it. Do not also add `nextlib-media3ext` or the class is duplicated. Library: `tv.p2160:player-core:0.2.16` (versionCode 28).
