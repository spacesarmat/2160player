**Какой APK скачать:** `arm` - подходит любому телефону и ТВ (рекомендуется). `arm64-v8a` / `armeabi-v7a` - поменьше, под одну архитектуру; `universal` - для всего, включая x86.

**Пульт во время буферизации**
- Пока идёт буферизация, фокус D-pad больше не прыгает по кнопкам. Он остаётся там, куда его поставили, поэтому «Аудио» и «Субтитры» открываются без предварительной паузы.
- На центральную кнопку фокус ставится при первом показе управления и после закрытия боковой панели, если внутри кнопок его ещё нет. Переход buffering/ready сам по себе фокус не двигает.
- Касания на телефоне не менялись. Индикатор загрузки по-прежнему внутри той же центральной кнопки.

Библиотека: `tv.p2160:player-core:0.2.19` (versionCode 31).

**English:** While the player is buffering, D-pad focus stays on the control the user selected, so the audio and subtitle buttons can be opened without pausing first. Focus moves to the centre button only when the controls first appear or a side panel has just closed and nothing in the controls is focused. A buffering/ready change does not move it. Touch behaviour is unchanged. Library: `tv.p2160:player-core:0.2.19` (versionCode 31).
