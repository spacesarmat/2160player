**Какой APK скачать:** `arm` - подходит любому телефону и ТВ (рекомендуется). `arm64-v8a` / `armeabi-v7a` - поменьше, под одну архитектуру; `universal` - для всего, включая x86.

**Полный аудит проекта и исправления**
- Плейлисты .m3u/.m3u8 с абсолютными путями (`C:/…`) снова разбираются: путь больше не принимается за относительный и не отсекается защитой от `../`. Трогает в основном Windows; на Android-путях поведение прежнее.
- Юнит-тесты проходят на Windows-машине: имя файла из `file://`-URI берётся не через последний сегмент пути (на Windows он весь путь), а через имя файла.
- Проверено целиком: сборка, все юнит-тесты, lint и релизная сборка с обфускацией (поля декодера FFmpeg в dex на месте).

Для пользователей приложения изменений в поведении нет.

Библиотека: `tv.p2160:player-core:0.2.20` (versionCode 32).
