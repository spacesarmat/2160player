**Какой APK скачать:** `arm` - подходит любому телефону и ТВ (рекомендуется). `arm64-v8a` / `armeabi-v7a` - поменьше, под одну архитектуру; `universal` - для всего, включая x86.

**WMV и VC-1 в AVI**
- AVI с fourcc `WMV1`/`WMV2`/`WMV3`/`WVC1` теперь играются: заголовок дорожки подменяется на MJPG-заглушку (иначе Media3 выбрасывает дорожку), а настоящий кодек и sequence header возвращаются декодеру.
- Если у устройства есть MediaCodec на `video/wvc1`, берётся он, иначе дорожку забирает FFmpeg (декодеры vc1/wmv уже есть в сборке на всех ABI, размер APK не вырос).
- Торрент-раздачи с такими AVI тоже играются.

**Торренты: честные сообщения об ошибках**
- Когда у раздачи нет пиров и данные не идут, плеер показывал «Контейнер не поддерживается или повреждён». Теперь показывает «Нет соединения с источником» — файл при этом здоров, просто ждать нечего.

Библиотека: `tv.p2160:player-core:0.2.21` (versionCode 33).

**English:** AVI files with `WMV1`/`WMV2`/`WMV3`/`WVC1` fourcc now play: the track header is swapped to an MJPG placeholder (otherwise Media3 drops the track) while the real codec and sequence header are handed to the decoder. Device MediaCodec is preferred for VC-1, FFmpeg takes over otherwise (decoders already shipped in every ABI). Also, when a torrent swarm has no data, the player now says "Cannot connect to the source" instead of "Container is not supported or damaged". Library: `tv.p2160:player-core:0.2.21` (versionCode 33).
