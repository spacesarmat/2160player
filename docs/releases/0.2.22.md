**Какой APK скачать:** `arm` - подходит любому телефону и ТВ (рекомендуется). `arm64-v8a` / `armeabi-v7a` - поменьше, под одну архитектуру; `universal` - для всего, включая x86.

**Тестовый режим (журнал действий)**
- Новый раздел Настройки → «Диагностика»: выключатель тестового режима и кнопка «Поделиться журналом».
- Пока режим включён, приложение записывает в файл (и в logcat, метка `p2160.actions`): жизненный цикл экранов, нажатия по кнопкам интерфейса, события плеера (открытие файла, пауза, перемотка, ошибки), события торрентов (добавление, выбор файла, ожидание данных). При падении приложения в журнал дописывается стек ошибки.
- Файл лежит во внутренней памяти, ротация по 4 МБ, старые файлы удаляются; выключенный режим не замедляет приложение.
- Нужен, чтобы разобраться в «у меня вылетает/не играет»: включите режим, повторите проблему и пришлите журнал.

Библиотека: `tv.p2160:player-core:0.2.22` (versionCode 34).

**English:** New Settings → «Diagnostics» section: a test-mode switch and a «Share the log» button. While enabled, the app records to a file (and logcat, tag `p2160.actions`): screen lifecycle, UI taps, player events (file open, pause, seek, errors) and torrent events (add, file select, waiting for data). On crash the stack trace is appended to the log. The file rotates at 4 MB; the disabled mode costs nothing. Use it to report «it crashes / won't play»: enable, reproduce, send the log. Library: `tv.p2160:player-core:0.2.22` (versionCode 34).
