# Десктоп

Отдельное приложение для macOS, Windows и Linux. Android-плеер и его CI не меняются.
Сборка живёт в каталоге `desktop/` со своим Gradle. Версия совпадает со следующим номером
приложения: сейчас это `0.2.26` (в релизе Android ещё `0.2.25`).

Движок - libmpv (FFmpeg), картинка рисуется в окне Compose. Звук остаётся внутри libmpv.
Библиотеки libmpv лежат в установщике, отдельно ставить mpv или VLC не нужно.

План и границы: [docs/plans/desktop.md](../plans/desktop.md).

## Скачать

CI кладёт файлы в артефакты сборки Desktop CI. Релиз и тег этим workflow не создаются:
их публикует владелец после проверки.

| ОС | Файл | Примечание |
|---|---|---|
| macOS | `2160player-0.2.26.dmg` | Подпись Apple отсутствует. Системные настройки могут потребовать открыть приложение через контекстное меню. Сборка CI - arm64. Торренты на Intel Mac этим пакетом libtorrent4j не покрыты. |
| Windows | `2160player-0.2.26.msi` | x64. WiX 3 собирает установщик в CI. |
| Linux | `p2160player_0.2.26_amd64.deb` и `2160player-0.2.26-linux-x64.tar.gz` | x64. Имя пакета `p2160player`: Debian не принимает имя, которое начинается с цифры. Ярлык и окно остаются «2160 Player». Нужны библиотеки рабочего стола (OpenGL или Vulkan, ALSA или PulseAudio, X11 или Wayland). Пакет `.deb` просит их у apt. Сам mpv в зависимостях не указан. |

Каталог данных:

- Linux: `~/.local/share/2160player`
- macOS: `~/Library/Application Support/2160player`
- Windows: `%APPDATA%\2160player`

Там лежат недавние файлы, позиция просмотра, громкость и сохранённые SMB-серверы (пароль в открытом виде, файл только для владельца).

## Запуск

- Файл: кнопка «Открыть файл», перетаскивание в окно или аргумент командной строки.
- Ссылка: «Открыть ссылку». Подходят `http`, `https`, HLS, `rtsp`, `rtmp`, `srt`, если их умеет собранный FFmpeg.
- SMB, DLNA, IPTV и торренты - кнопки на главном экране.
- Внешние субтитры: кнопка в панели «Субтитры» или перетаскивание `.srt`, `.ass`, `.vtt` на уже открытое видео. Файл с тем же именем рядом с роликом (`Movie.ru.srt` к `Movie.mkv`) подключается сам.
- Продолжение: если позиция не у самого начала и ролик не досмотрен (больше 97 % или, от 10 минут, хвост короче 30 с), плеер спрашивает «Продолжить» или «Сначала».

Клавиши, когда курсор не в поле ввода:

| Клавиша | Действие |
|---|---|
| Пробел, K | Пауза |
| Влево, вправо | 10 секунд |
| Вверх, вниз | Громкость |
| F, F11 | Полный экран |
| M | Без звука |
| Esc | Выход из полного экрана, иначе назад |

## Сеть

- SMB 2/3 (smbj): сервер, пользователь, пароль, домен. Пустой пользователь - гость. Общие папки и файлы. В libmpv файл попадает как локальный HTTP с Range.
- DLNA: SSDP или адрес вручную (`127.0.0.1:8200`, URL описания). Обзор ContentDirectory, воспроизведение HTTP-ресурса.
- IPTV: файл или URL плейлиста M3U. Если это HLS-манифест, открывается один поток. Иначе список каналов. Заголовки канала (`User-Agent`, `Referer`) передаются в libmpv.
- Торрент: magnet, URL `.torrent` или файл. Видео начинается, когда скачано нужное начало. Перемотка заказывает куски вокруг позиции. Это тот же `TorrentSession`, что у Android, плюс libtorrent4j для ОС.

## Чего нет

- NDI. В репозитории только заголовки NDI SDK для Android. Библиотека `libndi` в git не входит, а SDK для macOS, Windows и Linux скачивается с согласия лицензии Vizrt. CI не может положить её в установщик. NDI® is a registered trademark of Vizrt NDI AB. https://ndi.video/
- SMB-шары, DLNA, IPTV и торренты Android-приложения богаче (избранное, XMLTV, правила раздачи, передача на другое устройство). Здесь первый рабочий набор.
- Кадр ограничен 1920x1080: libmpv рисует в память, не в GPU-поверхность. Аппаратное декодирование выключено (`hwdec=no`), чтобы кадр стабильно появлялся.
- Blu-ray, ночной звук, жесты телефона и Intent API библиотеки к десктопу не относятся.

## Сборка

Нужен JDK 21.

```sh
cd desktop
python3 scripts/stage-libmpv.py   # на Linux заранее: apt install libmpv-dev patchelf
./gradlew test
./gradlew run --args="/path/movie.mkv"
./gradlew packageReleaseDeb       # или packageReleaseMsi, packageReleaseDmg на своей ОС
./gradlew createReleaseDistributable
```

`stage-libmpv.py` на Windows берёт сборку shinchiro `20261110` (x64). На macOS ставит mpv через Homebrew и подписывает dylib ad-hoc. На Linux копирует `libmpv.so.2` и кодеки, прописывает RPATH `$ORIGIN`.

Проверка кадра без окна: `./gradlew run --args="--dump-frame out.png movie.mkv"`.
